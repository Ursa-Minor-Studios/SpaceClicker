Space Clicker is a 2D clicker game with the goal of buying all of the upgrades. Space Clicker was the first game that I've ever made where I learned how to make resources increment, learned how the timer, game engine, and publishing works. This lowered the barrier of creating my next game, [Pixel Farming](https://github.com/Ursa-Minor-Studios/colonyFarming). Space Clicker isn't being maintained anymore, just remains an archive of the first game I ever built. Also the only game I built on Unity, I switched to Godot after that.
